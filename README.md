## Matheus Andrell

Hello, my name is Matheus Andrell, I'm a brazilian software engineer at **VMarket Food Solutions** working with backend, distributed systems and Generative AI. My main stack is Java and Spring Boot, building REST APIs, microservices and event-driven systems on AWS.

I'm currently pursuing a postgraduate degree in Software Architecture at [FIAP](https://www.fiap.com.br) and hold a degree in Information Technology from ENIAC.
